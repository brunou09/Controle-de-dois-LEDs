<h1>Circuito de Dois LEDs</h1>

Projeto realizado no Tinkercad com Arduíno e C++ para a matéria de IoT(Internet das Coisas), a sequência da simulação é:

1º aperto: acende o LED 1.<br>
2º aperto: apaga o LED 1 e acende o LED 2.<br>
3º aperto: apaga o LED 2.<br>
4º aperto: acende novamente o LED 1, reiniciando o ciclo.
